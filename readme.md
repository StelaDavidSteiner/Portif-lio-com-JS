## 📄 Formulário de Contato com Tabela de Dados
Este projeto é um formulário web que permite ao usuário preencher informações de contato e visualizar os dados enviados em uma tabela dinâmica ao lado do formulário. Ele foi desenvolvido com foco em práticas básicas de HTML5, CSS3 e JavaScript Orientado a Objetos.

## 🧰 Tecnologias Utilizadas
>- HTML5
>- CSS3
>- JavaScript (ES6)

## 🖼️ Visão Geral
O formulário coleta os seguintes dados:
>- Nome
>- E-mail
>- Telefone
>- Mensagem
>- Data de cadastro
>- Tipo de contato preferencial (E-mail, Telefone ou WhatsApp)

Ao enviar o formulário, os dados são exibidos na tabela ao lado. Também estão implementados botões de "Editar" e "Deletar" com mensagens placeholder (alertas), preparando o código para funcionalidades futuras.

## ✅ Funcionalidades
>- Validação básica de campos obrigatórios
>- Exibição dos dados em uma tabela
>- Mensagem de erro para campos obrigatórios não preenchidos
>- Estilização com layout moderno e cores suaves
>- Feedback visual ao passar o mouse nos botões
>- Arquitetura com classe JavaScript (Contato) para organizar os dados
